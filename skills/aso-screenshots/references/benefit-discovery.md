# Benefit Discovery

1. Analyze the codebase, README, and App Store metadata: what the user can do, the domain, premium/IAP offering, what onboarding highlights first.
2. Ask only targeted questions the code cannot answer (target audience, the #1 reason to download, competitors, what best reviews say).
3. Draft 3-5 benefits as `[VERB] + [SPECIFIC BENEFIT] - [why it drives downloads]` (e.g. "TRACK TRADING CARD PRICES", not "MANAGE YOUR COLLECTION").
4. Do not proceed until the user explicitly confirms the exact text; they have final say.
5. Save confirmed benefits to `.aso-screenshots/state.json` with app context, target audience, and refinement notes.
